# Requirements authority provenance

Requirements Baseline v1 is the original complete baseline. Requirements
Baseline v1.1 is the frozen product/acceptance state after explicit Lemon product
clarifications.

No standalone historical v1.1 artifact was recoverable, so the repository v1.1
file transparently consolidates the verbatim v1 source and the verbatim frozen
clarification input. Downstream frozen documents already identify v1.1 as their
requirements authority.
